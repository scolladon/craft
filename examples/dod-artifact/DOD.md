# Definition of Done

- [ ] Gates green — no committed change on a red gate
- [ ] Mutation testing clean — per-hunk survivors triaged (killed or proven equivalent)
- [ ] Architecture boundaries clean — module dependency rules pass (N/A if architecture phase is OFF)
- [ ] All acceptance criteria for the feature met and recorded per-criterion
- [ ] `NO-OP(verify):` token distinct from the mutation-absent note in the run record
