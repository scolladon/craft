# Named config example

This directory demonstrates the **named-config** surface: a second customization alongside
`.claude/workflow.md`, generated by `craft:init` and consumed by `craft:run --config <name>`.

## Files

| File | Purpose |
|---|---|
| `workflow.md` | Sample named-config manifest (YAML frontmatter + prose) |
| `README.md` | This file |

## How it works

1. **Generate**: `craft:init ci` interviews you, emits `.claude/craft-ci.md`, lints it in a
   temp path, and lands it atomically only on a clean lint.
2. **Consume**: `/craft:run --config ci <brief>` selects `.claude/craft-ci.md` for that run.

The name must be kebab-case (`[a-z0-9]+(-[a-z0-9]+)*`). The resolved path is captured once
by `init-config.js` and reused throughout — no raw-name re-splice at the move step.

See `workflow.md` in this directory for the manifest shape, and
[docs/guides/customizing.md](../../docs/guides/customizing.md) for the full injection catalog.
