# docs/

Two audiences, two trees.

- **Using craft?** Start in [`guides/`](guides/) — concepts and the full customization
  reference.
- **Contributing to craft?** Start in [`contributing/README.md`](contributing/README.md) —
  design docs, decisions, plans, contract specs, and the archive.

| Tree | Audience | Holds |
|---|---|---|
| [`guides/`](guides/) | craft users | concepts, customization guide, model-class matrix, measured cost comparison |
| [`contributing/`](contributing/README.md) | craft contributors | ADRs, design docs, plans, contract specs, archive, legacy program docs, DOD, metrics baseline |
