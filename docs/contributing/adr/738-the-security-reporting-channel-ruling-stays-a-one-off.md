# 738 — The security-reporting-channel ruling stays a one-off

- **Status:** accepted
- **Date:** 2026-11-20
- **Design:** docs/contributing/design/doctrine-register.md · **Supersedes/Refines:** none

## Context

ADR-504 went against the designer's recommendation and no doctrine entry covers it; every spike arm missed it and every arm escalated it.

## Options considered

1. **A one-off: its register line carries the refusal; no doctrine entry** *(recommended)* — pros: one ruling is no principle; the line is what catches a re-proposal / cons: a similar new case is not predicted.
2. **Draft a doctrine entry from it** — cons: a principle generalised from one case.
3. **Leave it unaddressed** — cons: no record of the choice.

## Decision

**adopted-as-recommended (no user judgment)** — no trade-off: the harvest rule drafts doctrine only when a ruling's rationale reaches beyond its candidate, and a similar new case still escalates.

## Consequences

- None.
